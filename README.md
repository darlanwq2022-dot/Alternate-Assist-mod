# Alternate Assist Mod v0.1.4 — Up Arrow Input Fix

Target: Windows · Geometry Dash 2.2081 · Geode 5.11.2.

## Fix in v0.1.4

The mod now supports setups where the Up Arrow is assigned to Player 2's primary jump input. This is a common mapping in Geode's Custom Keybinds defaults: Space/W are Player 1 jump keys, while Up is Player 2 jump.

A new setting, **Route Player 2 Jump to Player 1 in Single-Player**, is enabled by default. When a non-dual level is active, incoming P2 primary-jump events are routed to Player 1 before the Ship assist logic runs. This means the Up Arrow can control the normal Player 1 Ship and arm the stabilizer. The routing is deliberately disabled in dual mode, so Player 2 retains its original independent input.

Synthetic inputs generated by the stabilizer bypass this remapping and keep their explicit P1/P2 target. Other button IDs and non-gameplay contexts are passed to the original game handler unchanged.

## Existing functionality

- Adaptive Ship stabilization based on gravity-relative vertical velocity.
- Straightness slider from 0–100.
- Configurable maximum automatic CPS.
- Manual click activity window and cadence-based alignment.
- Optional Player 2 assistance in dual mode.
- Optional controller telemetry in the Geode log.

## Recommended test

1. Install v0.1.4 and make sure **Route Player 2 Jump to Player 1 in Single-Player** is ON.
2. Test an ordinary single-player Ship section using Up Arrow with Ship Assist OFF. Up should control P1 just like Space.
3. Enable Ship Assist and test Up Arrow again. The same input should now arm the stabilizer.
4. Test a dual level. The remapping should automatically stay out of the way there.

## Build

Build with the Geode SDK through CMake or the included GitHub Actions workflow. The source archive does not include a precompiled `.geode` file.

## Technical note

The compatibility route uses `GJBaseGameLayer::m_gameState.m_isDualMode` to distinguish single-player from dual gameplay. It does not change the player's position, velocity, gravity, or collision behavior.
