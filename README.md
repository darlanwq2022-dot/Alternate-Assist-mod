# Alternate Assist Mod (Geode)

## Build pelo GitHub
1. Crie um repositório e suba todos os arquivos desta pasta.
2. Vá em **Actions** > **Build Binaries** (roda sozinho a cada push).
3. Ao terminar, baixe o artifact **Build Output** e pegue o arquivo `.geode`.
4. Coloque o `.geode` em `Geometry Dash/geode/mods/`.

Antes: edite `mod.json` e troque `seunome` / `SeuNome`.

## Uso
- Funciona no modo normal e no practice (opção "Só no Practice Mode" vem desligada).
- Troque o modo durante o jogo pelo botão no menu de pausa (nenhum texto aparece durante o level).
- Ciclo: Extremo > Semi-reto > Pouca ajuda > Custom > OFF.
